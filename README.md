# Ashfaq Imran — Portfolio

Personal portfolio of Ashfaq Imran, AI-first Head of Product Design.

One scroll film: the sticky-note bust, the turning career cards, the crowd, then the work run (project panels, graphic design, the trophy), the career path, the AI workflow kit and the contact footer.

## Run it

Plain HTML, CSS and JavaScript, no build step. Open `index.html` in a browser, or serve the folder:

```
npx serve .
```

Libraries load from CDNs: GSAP 3.12.5 with ScrollTrigger, and Lenis 1.1.13.

## Files

- `index.html`: all content
- `styles.css`: layout, tokens and responsive rules
- `main.js`: the scroll film, the work timeline and the adaptive glass nav
- `assets/`: renders made with Higgsfield, project key visuals in `assets/posters/`
